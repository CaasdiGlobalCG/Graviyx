### Why

- The site was built on an Operon palette with a neon-green accent, a display font that was never
  actually loaded, and a 404 page that rendered unstyled. None of that matched the supplied brand
  book, and the brand book is explicit: *"The GRAVIYX palette is intentionally monochromatic… No
  decorative accents are introduced."*
- `--font-display` was set to `"NeueHaasGrotesk"` but only Inter was ever loaded, so **every heading
  on the site was rendering in the Helvetica fallback**.
- `prefers-reduced-motion` was honoured for CSS only. Every `motion.*` animation and both SMIL
  markers ignored it.
- Three animations moved layout or paint properties (`height` in two places, `background-position` in
  two keyframes), which the repo rules forbid.
- The favicon was the neon-green accent, not a Graviyx mark.

### How It Works

**Tokens.** `src/styles.css` is the single writer of the design system. Brand palette tokens
(`--ink`, `--paper`, `--paper-2`, `--steel-90…15`) feed semantic aliases (`--bg`, `--surface`, `--fg`,
`--muted`, `--meta`, `--border`) so the ~150 existing `bg-bg` / `text-fg` class usages kept working
while their values changed to brand values. `@theme inline` maps everything into Tailwind.

**Honesty about values.** The brand PDF publishes exactly one numeric colour — Paper `#FAFAF7`.
Ink and the six steel neutrals have **no printed hex, RGB, CMYK or Pantone**. Ink is therefore taken
from the supplied official logo files (which are pure `#000000`), and the steel ramp is derived and
labelled `DERIVED` in the file header. Nothing is presented as brand-published when it is not.

**Assets.** `GRAVIYX WORDMARK.png` and `GRAVIYX COMPLETE LOGO.png` are RGB with a white background
baked in, so they cannot sit on Paper. They are keyed luminance-to-alpha instead — the correct
unmatting for a black-on-white asset, which preserves anti-aliasing exactly. `Graviyx_Brand_Logo.png`
turns out to store its wordmark as fully transparent black (invisible in reality; only alpha-ignoring
renderers show it), so the wordmark comes from the standalone file. The favicon is regenerated from
the symbol, in Ink on Paper.

**Motion.** A kit in `styles.css` (`--motion-instant/fast/base/slow/scene/draw`, `--ease-signal`,
`--ease-cut`) is the only place durations and curves live. `--ease-signal` is the curve the
components were already using inline, now formalised. Reduced motion is handled globally by
`<MotionConfig reducedMotion="user">` in the root route, which covers every `motion.*` animation;
the two SMIL `<animateMotion>` markers are gated individually because Motion cannot reach them.

chosen from real options, then applied consistently.

### How It Works

**Neumorphism, as a scoped exception.** The repo rule is "structure with hairlines, not
shadows"; neumorphism is made entirely of shadows. It is permitted, but constrained:
- One surface set serves two canvases. `neu-canvas` (Paper-2) and `neu-canvas-dark`
  (steel-90) each re-point `--neu-surface`, `--neu-light` and `--neu-dark`, so
  `neu-raised`/`neu-flat`/`neu-pressed`/`neu-inset`/`neu-control`/`neu-field` work unchanged
  on either.
- **The dark canvas is a dark grey, never pure Ink.** Black leaves no room for a shadow
  darker than itself, so the effect collapses into a flat rectangle.
- **A surface's background must equal its parent canvas exactly**, or the paired shadows read
  as a drop-shadowed box. Every section rendering a `neu-*` surface carries a canvas class.
- **Both secondary text tones are re-pointed on the light canvas** — `--muted` to steel-70
  (~9.4:1) and `--meta` to steel-50 (~4.7:1). steel-30 is ~2.5:1 on a mid-tone and fails. The
  token-level fix also covers SVG `fill="var(--meta)"`, which a class-level fix would miss.
- No Tailwind `shadow-*` anywhere — that scale is blue-black and reads as a second system.

### Four defects found and fixed, three of them mine

1. **Content was invisible.** 73 elements per page carried inline `opacity:0` and depended on a
   JS `whileInView` observer to come back. If it never fired — JS disabled, hydration failure,
   an embed that does not scroll — the page rendered blank. `Reveal` is now CSS scroll-driven
   with a **visible base state**; both maps render unconditionally; 20+ call sites swept.
2. **Every decorative grid was drawing solid, not at 5%.** `color-mix(in oklab, currentColor
   5%, transparent)` cannot be resolved at build time, so the compiler dropped the percentage
   and emitted a solid line — ~20× too heavy. Fixed with `--veil` / `--veil-strong` tokens
   re-pointed per surface.
3. **The focus ring was being destroyed.** `:focus-visible` used `box-shadow`, which lives in
   the base layer, so any utility setting `box-shadow` overwrote it. Now an outline.
4. **A 2.1 MB scratch file** an agent left in the repo root got committed. Removed, with a
   `.gitignore` guard.
